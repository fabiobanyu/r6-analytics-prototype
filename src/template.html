Mengikuti filter utama

Satu operator dihitung sekali per peta walau tercatat pada beberapa indeks ronde. Ban tidak dihitung sebagai pemilihan atau kemenangan.

Cakupan dan pembaruan data operator

Statistik pemilihan memakai snapshot agregat publik r6tv, pihak ketiga yang menganalisis replay. Cakupan replay lebih kecil dari seluruh ronde pada sumber hasil resmi. Angka kedua sumber tidak digabung untuk membuat denominator baru.

Data hasil Ubisoft tetap diperiksa setiap 6 jam. Snapshot tambahan operator ini diperbarui melalui impor sumber terverifikasi secara terpisah; tidak diklaim sebagai feed otomatis atau statistik semua event. Data ban di atas mengikuti pembaruan Ubisoft.

Hasil pertandingan resmi

Nama tim mengikuti nama terkini sumber. Kekosongan statistik tetap kosong. Metrik operator memakai sumber dan cakupan terpisah yang dijelaskan pada tab Operator intel.

Asumsi model

Elo awal 1500, faktor 400, K=24; satu pembaruan per series. Tidak ada penyesuaian roster, peta, patch, region, atau masa jeda.

Evaluasi historis terbatas ini belum membuktikan performa di masa depan. Tidak ada telemetri pertandingan publik/ranked.

Pembaruan otomatis hasil

  1. Buka Jalankan Pembaruan Otomatis.cmd.
  2. Biarkan proses dan internet aktif. Pemeriksaan resmi setiap 6 jam.
  3. HTML memeriksa cache lokal setiap 60 detik.

Menutup pembaru atau mematikan komputer menghentikan polling. Tombol “Periksa cache” hanya membaca file lokal.

Jika sumber atau validasi gagal, snapshot sebelumnya dipertahankan. Snapshot operator tambahan tidak diperbarui oleh polling hasil ini.
