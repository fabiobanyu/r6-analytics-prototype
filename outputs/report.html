Yang sudah diperbaiki

  • Generator pertandingan dan prediksi yang memaksakan hasil dihapus. Data nyata berasal dari __NEXT_DATA__ pada halaman publik resmi Ubisoft.
  • Grain terpisah untuk series, peta, ronde, pemain-peta, dan operator ban. Kemenangan 0% dan statistik yang hilang diperlakukan berbeda.
  • Model hanya mempelajari series selesai non-forfeit. Prediksi dibuat sebelum label hasil dipakai; timestamp sama diproses per batch.
  • Metadata mencakup URL, waktu unduh UTC, status HTTP, checksum HTML, serta SHA-256 ekstrak yang disimpan dalam gzip.
  • Pembaruan setiap 6 jam; satu penulis, timeout, retry, batas koneksi, pemeriksaan checksum, validasi sebelum publikasi snapshot, dan fallback pada cache terakhir.

Hasil konkret

Dataset memuat 414 series (410 selesai, 4 terjadwal dengan tim diketahui), 620 peta selesai, 6696 ronde, dan 6200 baris pemain-peta. Sebanyak 46 slot/record belum lengkap dicatat di metadata. Tidak ada tim atau hasil pengganti yang dibuat.

Batas interpretasi

Cakupan terdiri dari event global musim 2026-2027 dan stage regional yang ditampilkan sebagai default saat penemuan sumber, bukan arsip lengkap seluruh musim. Nama organisasi mengikuti nama terkini sumber. Detail yang gagal/tidak tersedia tetap kosong; 0 nama peta belum tersedia. Tidak ada data match publik/ranked. Elo tidak mengetahui roster, patch, peta, faktor region, atau masa jeda.

Validasi dan pengujian

Jalankan python scripts/validate_data.py untuk mencocokkan setiap nilai hasil/statistik ternormalisasi dengan ekstrak sumber terunduh. npm test menguji grain, kebocoran label, filter, detail, ekspor CSV, pembaruan cache, sumber rusak, dan jaringan gagal.

Uji interaksi memakai jsdom. Itu bukan pengujian visual browser. Browser pengujian menolak protokol file://; layout, dialog native, dan unduhan browser tetap perlu uji manual di browser pengguna. Prototype ini belum dinyatakan siap produksi.

Menjalankan dan memperbarui

Buka index.html atau Buka Demo.cmd. Untuk polling otomatis portabel, jalankan Jalankan Pembaruan Otomatis.cmd dan biarkan proses serta internet aktif. HTML memeriksa file cache lokal setiap 60 detik. PC mati atau proses ditutup berarti polling berhenti. Tidak ada deployment.
